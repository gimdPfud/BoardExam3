# 📝 BoardExam3 - 세번째 게시판 프로젝트

학원에서 배운 기술을 활용하여 제작한 세번째 게시판 프로젝트입니다.

## 소개
* 프로젝트명: BoardExam3 (세번째 게시판)
* 개발 형태: 수업 실습 프로젝트
* 개발 기간: 2025-03-27부터 시작
* 목적: 파일 업로드 기능과 상품 관리 시스템 구현

## 사용 기술
* Language: Java 17
* Database: MariaDB
* Frontend: HTML
* Template Engine: Thymeleaf
* 기타: Bootstrap 5 (UI 스타일링)

## 주요 기능

### 상품 관리
* 상품 목록 조회
* 상품 등록
* 상품 상세 보기
* 상품 수정
* 상품 삭제

### 파일 업로드
* 상품 이미지 업로드
* 파일 저장 및 관리
* 이미지 미리보기

### 기본 기능
* 페이징 처리
* 작성일자 표시
